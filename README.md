# 🍴 About Koupaat

Koupaat Restaurant is a modern restaurant web project focused on creating a clean, aesthetic, and user-friendly online presence for a restaurant brand.

The project emphasizes:

* Elegant UI/UX
* Smooth navigation
* Responsive layouts
* Interactive design
* Modern web experience

This website was designed to showcase restaurant services, menu presentation, customer engagement, and a premium digital experience.
